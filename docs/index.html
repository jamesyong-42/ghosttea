Why Ghosttea

The shortcut to a terminal that feels right.

Terminal behavior is a product surface. Ghosttea packages the difficult parts so your team can focus on the experience around it.

01 / FEEL

Native where users notice.

Ghostty terminal semantics, native shaping, ligatures, Unicode, reflow, selection, scrollback, and GPU rendering—without an iframe or a DOM grid.

02 / FIT

Your UI stays yours.

Use a complete workspace or mount one terminal surface inside your own product.

03 / CONTROL

Humans and agents, in order.

Typed automation yields safely when a person starts typing.

04 / CONTINUITY

A session, not a screenshot.

Share logical terminal state across devices. Remote views render locally, stay sharp, and preserve input and resize authority.

One model, every surface

Local speed. Remote continuity.

The same terminal model powers a local Electron pane, a native iOS SSH session, or a shared terminal on another device.

Local path

Your process. Native PTY. Zero detours.

Ghosttea owns the PTY, terminal state, shaping, and frame lifecycle. Your app owns the chrome and product logic.

app→ PTY→ Ghostty VT→ GPU
Shared path

Move the state. Render where you are.

Truffle carries compact logical updates. Each receiving device shapes and renders locally instead of streaming pixels.

session→ logical sync→ replica→ GPU

Production-minded

Built for the edge cases users feel.

The runtime is opinionated about ordering, backpressure, recovery, and memory because terminal quality lives in the details.

01

Fast frame path

Transferable binary frames travel from the utility process straight to a shared render worker—outside Electron main and React state.

02

Ordered interaction

View epochs reject stale input and resize operations. Human input invalidates older automation instead of waiting behind it.

03

Bounded by design

Frame credits, catalog budgets, targeted resynchronization, and hidden-session eviction prevent invisible work from growing forever.

04

Measured, not guessed

Native, WebGPU, replication, and physical-device harnesses keep performance claims tied to repeatable evidence.

Honest status

Shipping desktop. Hardening Apple.

Apple Silicon macOS and x64 Windows desktop paths are release-gated. The native iOS 18.1+ stack is implemented and device-tested, with external release qualification still in progress.

Linux endpoint support exists in the service, but there is no published Ghostty VT bundle for Linux today.
