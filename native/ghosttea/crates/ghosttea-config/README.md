# ghosttea-config

Versioned Ghostty-compatible configuration loading shared by Ghosttea's
daemon, Electron, and Apple FFI hosts.

The crate preserves configured values and diagnostics while projecting the
settings Ghosttea can currently apply. Its compatibility target and intentional
gaps are documented in the repository's
`docs/ghostty-config-compatibility.md`.

The released Ghostty config source is pinned independently from the VT runtime
in `native/ghostty-config.lock.json`. Regenerate and verify the source-derived
key catalog and X11 color table with:

```sh
npm run sync:ghostty-config -- --source /path/to/ghostty-v1.3.1 --check
```

`src/x11-rgb.txt` is generated byte-for-byte from Ghostty's
`src/terminal/res/rgb.txt`, which upstream identifies as the X.Org `rgb.txt`
catalog under the MIT/X11 license.
